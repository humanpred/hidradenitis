## All functions

- [`hasi_r_num()`](https://humanpred.github.io/hidradenitis/reference/hasi_r_num.md)
  : Calculates the HASI-R score for each patient and visit.

  : Calculates HiSCR scores given a percentage parameter.

  : Converts HS-PGA numerical scores to character values.
- [`hs_pga_num()`](https://humanpred.github.io/hidradenitis/reference/hs_pga_num.md)
  : Calculates HS-PGA scores based on abscess, draining fistula, and

- [`ihs4_char()`](https://humanpred.github.io/hidradenitis/reference/ihs4_char.md)
  : Converts IHS4 numerical scores to character values.
- [`ihs4_num()`](https://humanpred.github.io/hidradenitis/reference/ihs4_num.md)
  : Calculates IHS4 scores based on abscess, draining fistula, and
  inflammatory nodule counts.
